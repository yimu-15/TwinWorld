# PAPER_EXPERIMENT_TIMELINE — TwinWorld 第1–110号实验研究脉络

> 只读审计产物。全部事实来自真实源码 / 报告 JSON / 审计 JSON / 检查点 / 日志。未执行的实验已明确标记，不写成"完成"。

## 研究问题演变（一句话链条）

1. **P0**：验证"严格匹配的被动轨迹中，隐藏机制不同的两个世界无法区分；对 A 施加同一外力后，B 的响应不同"这一物理可辨识性 sanity-check。
2. **P1**：把 P0 的 CPU 玩具模型迁移到 MuJoCo 刚体，验证被动等价 + 耦合使 B 对 A 干预产生响应，并隔离隐藏耦合（匹配 A 运动）。
3. **P2**：扩展到三机制/五机制与开集（未知机制拒绝），确认"B 观测 + 主动 pulse 探针"是最具信息量的辨识通道。
4. **P3**：核心算法线——从"已知定律重拟合"到"受限结构修订"到"证据门控主动干预"，研究主动实验能否区分被动不可分的机制，并探索门控省功与自适应动作。
5. **P4**：四条并行收官线——(M) 物理先验/参数域/动作剂量的机制识别；(S) 求解器预算与嵌套域违例；(T) 预测边际理论一致性；(B/G) 与经典系统辨识方法（PEM/AIC/BIC、方程误差 EQERR、TRF/SLSQP）的公平横向比较，及独立 ODE 生成器的"参数冻结 vs 重新拟合"。

## 阶段与实验映射

### P0（1–4）：最小验证（CPU twincore）
- 01 生成 / 02 验证 / 03 基线 / 04 绘图。被动多数类=50%，特权主动 oracle=100%（**非可推广**）。

### P1（5–9）：MuJoCo 迁移
- 05 冒烟 → 06 固定协议（P1-B）→ 07 匹配 A 运动（P1-C）→ 08 噪声鲁棒（P1-C2）→ 09 未知参数非特权诊断（P1-C3）。B 观测在测试集达 100% 可分。

### P2（10–19）：三/五机制 + 开集 + 探针
- 10 三机制冒烟 → 11 数据集 → 12 固定监督基线（B_only 0.878）→ 13 视窗 → 14 探针可行性 → 15 五机制冒烟 → 16 五机制/五探针审计（pulse 恒最优，自适应余量=0）→ 17 开集试点 → 18 结构 vs 参数偏移 → 19 激励幅值审计。

### P3（20–71）：主动机制辨识与结构修订（分三子段）
- **P3-A0–A2（20–25）**：已知定律重拟合与受限结构修订（deadzone/cubic），非特权 BIC 选择器。
- **P3-A3–A4（26–32）**：欠激励压力、结构修订 vs 重拟合消融、证据门控停/强策略；32 号冻结策略死区压力测试（机制感知零误停）。
- **P3-A5–A6（33–54）**：可辨识性信号、观测相容集、交叉干预结构验证、六机制开集、校准修订、激励漂移失败归因。**大量只读/仅 PRIVATE 实验（33,34,35,36,37,38,39,41,43,44,46,49,53）无正式 report**。
- **P3-A7–A8（55–71, 78）**：证据门控升级、结构等价审计、动作族（high/reverse/biphasic）、affine 线性增益 A 预测器、双向动作选择。**78 号动作排序审计：分歧 margin 不能可靠排序动作（负面）**。

### P4（72–110）：收官四条线
- **P4-M（72–90）**：可辨识性极限、物理域拟合、先验失配、候选域因子（OOO 最优）、动作×先验交互、幅值剂量反应。
- **P4-S（91–93）**：求解器预算、嵌套域违例（deadzone 33–36 处，判定为数值缺口而非物理）。
- **P4-T（94–95）**：预测边际理论一致性（P90 幅度剂量与真律边际一致）。
- **P4-B/G（96–110）**：经典系统辨识基线（PEM/AIC/BIC、EQERR、TRF/SLSQP）公平比较 + 独立 ODE 生成器冻结 vs 重拟合。**110 号 P4-B3C 为收官确认实验**。
